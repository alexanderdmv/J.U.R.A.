# Резервные копии и восстановление

## Что это
Одна команда создаёт **один зашифрованный файл** `jura-backup-ДАТА-ВРЕМЯ-NN.jurabak`: базы, память, журнал и (в заголовке)
файл хранилища. Внутри всё зашифровано ключом из твоей иерархии ключей; файл можно хранить где угодно.

**Для восстановления нужны только две вещи: файл копии и бумажный код** (или пароль). Больше ничего — ни старого компьютера, ни `~/.jura`.

## Настройка (один раз)
Копии должны лежать на **другом физическом диске**, чем данные (`~/.jura` обычно на C:). Если диск D: — отдельный физический диск:

```powershell
# только для текущего окна:
$env:JURA_BACKUP_DIR = "D:\jura-backups"
# навсегда (подействует в новых окнах терминала):
setx JURA_BACKUP_DIR "D:\jura-backups"
```
Копии внутри папки данных J.U.R.A. программа не принимает: они пропали бы вместе с ней.

## Команды
```
backup                      создать копию (в jura shell: «backup»)
backup --keep 30            создать и оставить только 30 последних
backup-list                 показать копии
python -m jura backup-verify ФАЙЛ        расшифровать и проверить копию (ничего не записывает)
python -m jura restore ФАЙЛ --to ПАПКА   восстановить в ПУСТУЮ папку (существующее не перезаписывается)
```
Перед созданием копии проверяется журнал событий. Если он повреждён, копия **не создаётся** — это сигнал разобраться, а не молча сохранить испорченное.

## Если украли компьютер
1. Поставь Python, скачай код проекта (GitHub / твой архив), `pip install -e .`
2. Возьми последний файл `.jurabak` (с диска D:, из второй копии, из облака).
3. `python -m jura restore ФАЙЛ --to C:\Users\ТЫ\.jura-new` — на вопрос про пароль нажми **Enter**, введи **бумажный код**.
4. Укажи папку: `$env:JURA_HOME="C:\Users\ТЫ\.jura-new"` и запусти `python -m jura shell`.
5. Смени пароль (старый могли подсмотреть) и выпусти новый бумажный код (`rotate_recovery_code`, команда появится в Phase 1).

## Правило 3-2-1 (куда двигаться дальше)
1. Рабочие данные на Core. ✅
2. **Копия на втором диске (D:)** — вот это сейчас. ✅ вручную
3. **Копия вне дома** (облако или USB в другом месте) — зашифрована тем же ключом, провайдер видит только шифротекст. ⏳
Доступы к облаку и резервные коды 2FA храни **отдельно** от компьютера: иначе после кражи в облако не зайти.

## Ограничения (честно)
- Копии пока **создаются вручную**. Автоматический график — Phase 1 (планировщик).
- Копия собирается в оперативной памяти целиком: для личного объёма нормально, для гигабайтов — нужна потоковая упаковка.
- «Забыть» запись нельзя из уже сделанных копий — только дождаться их удаления (`--keep`).
- Учения восстановления — **раз в квартал**: `backup-verify`, а лучше полный `restore` в пустую папку.
