# Голос

Всё локально: звук и текст не покидают компьютер. Решение и обоснование — `docs/adr/0011-voice-stack.md`.

## Что уже есть (v0.4)
`voice-check` · `listen` (микрофон → текст) · `speak` (текст → голос) · `echo` (повторяет услышанное) — вход и выход голосом.
**«Мозга» пока нет**: J.U.R.A. слышит и говорит, но отвечать по смыслу начнёт, когда подключим модели и диалоговое ядро.

## Установка (Windows)
```
pip install -e .          # голос ставится вместе с проектом
python -m jura setup       # скачивает модель распознавания и проверяет голос
python -m jura voice-check
```
`voice-check` по пунктам скажет, что работает, а что нет (пакеты, микрофон, голоса, модель распознавания).
**При первом запуске модель распознавания скачивается из интернета (сотни МБ)** — нужен интернет и пара минут.
Микрофон: Параметры Windows → Конфиденциальность → Микрофон → разреши доступ классическим приложениям.

```
python -m jura listen                  Enter → говори → Enter  → текст и скорость (RTF)
python -m jura listen --remember       то же + сохранить в память (зашифровано; аудио нигде не сохраняется)
python -m jura listen --file а.wav     распознать готовый файл (WAV 16 кГц, моно, 16 бит)
python -m jura speak "Привет, я Юра"   произнести
python -m jura echo                    сказал → услышал → повторил; «стоп» — выход
```
Настройки (необязательно, переменные окружения): `JURA_STT_MODEL` (`gigaam-v3-e2e-rnnt` — с пунктуацией),
`JURA_STT_QUANT=int8` (быстрее на процессоре), `JURA_MIC_DEVICE` (номер из `voice-check`),
`JURA_TTS_VOICE`, `JURA_TTS_RATE` (−10…10).

## Твоё железо и как мы его используем
| Ресурс | Роль |
|---|---|
| Процессор Ryzen 5 2600, 16 ГБ ОЗУ | Распознавание речи (GigaAM), синтез |
| GPU GTX 1660 Ti, 6 ГБ | **Свободна** — под локальную языковую модель для секретных данных (S1). 6 ГБ — это впритык для моделей порядка 7–8 млрд параметров в 4-битном виде; конкретику решим на этапе моделей по актуальным данным |

Опубликованная скорость GigaAM снята на более новых процессорах; на твоём она будет ниже. `listen` покажет реальный RTF
(время распознавания ÷ длительность звука; меньше 1 — быстрее реального времени). Если медленно: `JURA_STT_QUANT=int8`.

## Честные ограничения
- **Проверено мной:** логика, преобразование звука, вызовы библиотек (с подставными модулями), защита текста от инъекции.
  **Не проверено:** настоящий микрофон, настоящая модель, настоящий PowerShell/SAPI — это проверяется у тебя первым запуском.
  Присылай вывод `voice-check` и ошибки — чиним по ним.
- Русский голос Windows (Microsoft Irina) есть не на каждой системе. Если `voice-check` его не видит, речь будет с акцентом —
  тогда подключаем Piper.
- GigaAM — русская модель: английские слова и термины могут распознаваться хуже. Проверь на своих фразах.
- Распознавание ждёт Enter для остановки записи; автоматическое определение конца фразы и слово-активатор — следующий этап.

## Про «распознавать мой голос»
- **Понимать слова** (STT) — делает `listen`.
- **Узнавать, что говоришь именно ты** — удобство, а не защита: голос можно записать и подделать. Поэтому голос **не подтверждает**
  рискованные действия (L2/L3): подтверждение идёт на экране или Face ID. Узнавание говорящего добавим позже.
