# Голос

Всё локально: звук, текст и разговор не покидают компьютер. Решения и замеры — `docs/adr/0015-multilingual-voice-dialogue.md`
(раньше — `0011-voice-stack.md`).

## Что умеет (v0.8)
- **Разговор голосом** — `talk`: говоришь, J.U.R.A. отвечает голосом. Ответ приходит примерно через 3 секунды.
- **Языки:** русский, украинский, чешский, английский, в том числе **вперемешку в одной фразе**. Отвечает в той же смеси.
- **Один голос** на все языки. Каждый кусок произносится по правилам своего языка. Чешский звучит с лёгким русским акцентом (см. ниже).
- **Сленг:** то, что знает модель, плюс **твой личный словарь** (`lexicon`), который растёт вместе с тобой.
- Пока **только разговаривает**: ничего не отправляет и не покупает. Действия появятся через политики, как остальное в J.U.R.A.

## Первый запуск (один раз)
```
pip install -e .
python -m jura setup        ← скачивает распознавание (Parakeet), голос (Piper) и готовит модель jura-gemma3 в Ollama
python -m jura init         ← если хранилища ещё нет (пароль + бумажный код)
python -m jura shell
jura> model add local-main local jura-gemma3 --context 2048 --max-output 300
jura> talk
```
В `talk`: **Enter — начать говорить, Enter — закончить**. Выход: скажи «стоп», «досить», «stop» или «konec».
`talk --typed` — реплики печатаешь, а ответ звучит голосом. `talk --mute` — без звука.
`chat` — тот же собеседник текстом. `chat --reset` — начать разговор заново.

## Личный словарь (сленг, свои словечки)
```
jura> lexicon add вайб = настроение, атмосфера
jura> lexicon add шарить = разбираться в чём-то --also шаришь,шарю
jura> lexicon list
jura> lexicon remove вайб
```
`--also` — как ещё это слово может прозвучать или как его распознаёт микрофон. Если распознавание упорно пишет
твоё словечко по-своему, добавь это написание сюда. Модели подкладываются **только прозвучавшие** слова,
поэтому словарь может быть большим. Он хранится зашифрованным.

## Модели и где они лежат
| Что | Модель | Где |
|---|---|---|
| Распознавание | Parakeet TDT 0.6B v3, int8 (ru/uk/cs/en + ещё 21 язык) | `JURA_MODELS_DIR\hf` |
| Голос | Piper `ru_RU-irina-medium` | `JURA_MODELS_DIR\piper` |
| «Мозг» | gemma3:4b → `jura-gemma3` (окно 2048, все слои на видеокарте) | `OLLAMA_MODELS` |

`JURA_MODELS_DIR` по умолчанию `~/.jura-models`. На ноутбуке владельца это `D:\jura-models`, потому что на C: мало места.
Установщик задаёт папку флагом `install.cmd --models-dir D:\jura-models`.

Настройки (переменные окружения, все необязательные):
`JURA_TTS_VOICE` (имя голоса из папки piper), `JURA_TTS_SPEED` (1.0 — обычная, 1.2 — быстрее),
`JURA_STT_MODEL` (`gigaam-v3-rnnt` — только русский), `JURA_STT_QUANT` (`none` — полная модель), `JURA_MIC_DEVICE` (номер из `voice-check`),
`JURA_TTS=windows` — голоса Windows вместо Piper.

Другой голос: скачай его (`python -m piper.download_voices --download-dir D:\jura-models\piper ИМЯ`) и задай `JURA_TTS_VOICE`.
Уже скачаны для сравнения: `ru_RU-denis-medium` (мужской), `uk_UA-tetiana-high`, `uk_UA-mykyta-high`, `cs_CZ-jirka-medium`.

## Диагностика
```
python -m jura voice-check            ← пакеты, микрофон, голос, модель распознавания — по пунктам
python -m jura listen                 ← Enter, говори, Enter → текст и скорость (RTF; меньше 1 — быстрее реального времени)
python -m jura speak "Привіт, як справи? Let's go!"
python -m jura echo                   ← повторяет услышанное; «стоп» — выход
```
Микрофон: Параметры Windows → Конфиденциальность → Микрофон → разреши доступ классическим приложениям.

## Честные ограничения
- **Проверено на ноутбуке владельца без микрофона:** вопрос синтезировался голосом, распознавался, модель отвечала, ответ снова синтезировался.
  **Настоящий микрофон и твоё произношение** проверяешь ты. Присылай, что распознаётся неправильно.
- **Чешский** одним голосом звучит с русским акцентом. Голос, одинаково хороший на всех четырёх языках, среди локальных моделей не нашёлся.
  Если чешский важнее одного тембра, поставь `JURA_TTS_VOICE=cs_CZ-jirka-medium`: чешский станет чистым, остальные языки — с акцентом.
- **Маленькая модель** (4B) иногда теряет нить разговора и слабее знает украинский и чешский сленг. Словарь помогает.
  Качественный скачок даст модель побольше (ПК с 6 ГБ, сервер) или облако после Redaction Gateway.
- Запись по Enter: автоопределения конца фразы, слова-активатора и перебивания пока нет.
- Голос **не подтверждает** рискованные действия (L2/L3): голос можно записать и подделать. Подтверждение идёт на экране или через Face ID.
