# ADR-011 — Голосовой стек
**Статус:** Accepted; распознавание (GigaAM → Parakeet v3) и синтез (SAPI → Piper) заменены в ADR-015 — нужно было 4 языка

## Контекст
Русскоязычный владелец, речь должна обрабатываться **приватно, локально**. Железо: Ryzen 5 2600 (6 ядер), 16 ГБ ОЗУ,
GTX 1660 Ti 6 ГБ, Windows. Нужно: понимать речь, отвечать голосом, не требуя сложной установки.

## Решение
| Часть | Выбор | Почему |
|---|---|---|
| Распознавание (STT) | **GigaAM v3** (Сбер) через **onnx-asr**, на **процессоре** | Модель создана для русского; ставится `pip`, без PyTorch и без CUDA/cuDNN; оставляет GPU свободной |
| Синтез (TTS), старт | **Голоса Windows (SAPI)** через PowerShell | Ничего не ставить; работает сразу |
| Синтез, следующий шаг | **Piper** (быстро, русские голоса) или **Silero** (естественнее, но тянет PyTorch) | Заменяются за тем же интерфейсом `TextToSpeech` |
| Запись | **sounddevice**, push-to-talk (Enter) | Просто и надёжно; слово-активатор — позже |

Правила: аудио живёт **только в памяти** и не пишется на диск; текст в PowerShell передаётся через переменную окружения
(инъекция команды невозможна); голос **не подтверждает** L2/L3; зависимости голоса ставятся обычной командой `pip install -e .` (владелец меняет компьютеры — выбирать extras не должен), а импортируются лениво: поломка голоса не ломает ядро. Модель распознавания скачивает `python -m jura setup`.

## Альтернативы
- **faster-whisper (Whisper) на GPU:** отлично для многоязычности, но на Windows требует точного набора CUDA/cuDNN, а по замерам авторов
  GigaAM точнее на русском. Остаётся запасным вариантом (например для английских терминов).
- **Облачные STT/TTS:** отклонено — приватность.
- **Vosk, T-one:** слабее или без пунктуации по замерам авторов GigaAM-реализаций.

## Последствия
- Новые сторонние зависимости: `onnx-asr`, `onnxruntime` (не 1.24.1 — известная несовместимость), `numpy`, `sounddevice`.
- При **первом запуске** модель скачивается из интернета (сотни МБ); дальше сеть не нужна. Это точка доверия к источнику модели.
- Скорость на твоём (более старом) процессоре будет ниже опубликованной — её **измеряет** `listen` (показывает RTF).
- Риск: GigaAM v3 — русская модель; английские слова и термины (код!) могут распознаваться хуже. Проверить; запасной вариант — Whisper.
- Замеры точности — авторов моделей и библиотек, на их наборах данных; независимыми не считаются.
