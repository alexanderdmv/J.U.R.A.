# ADR-004 — Транзакции и outbox
**Статус:** Draft (реализовано минимально)

## Решение
- Любое изменение состояния вместе с событием — одна транзакция; вложенные — SAVEPOINT.
- Необратимые действия (L2+, не idempotent) защищены outbox: ключ = `задача:хэш вызова`.
  Нет ключа → записать и выполнять. `done` → не выполнять повторно. `pending` → исход неизвестен, **не повторять, звать человека**.

## Последствия
Гарантия: не более одного выполнения на (задача, вызов). Диспетчер внешних эффектов и восстановление
после сбоя — Phase 1 (вместе с durable execution).
