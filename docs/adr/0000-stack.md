# ADR-000 — Язык и стек
**Статус:** Accepted (решение владельца проекта)

## Контекст
Код пишет Claude, владелец читает и понимает, но не пишет. Проект долгий; сложность — в архитектуре
и взаимодействии частей, а не в алгоритмах. Главные рабочие инструменты: VS Code, Windows-узел, iPhone.

## Решение
**Python 3.11+.** Ядро — простой код без метапрограммирования, на стандартной библиотеке;
единственная зависимость ядра — `cryptography` (только в `vault.py`). Тесты — `unittest` (ничего ставить не надо).

## Альтернативы
- TypeScript везде — сильные типы, но слабее AI/voice-экосистема.
- Ядро на Go/Rust + AI на Python — надёжнее, но два языка и дороже для одного человека на старте.
- C#/.NET — хорошая интеграция с Windows, уже AI-экосистема.

## Последствия
- Простота кода = надёжность: читаемо владельцем, проверяемо тестами.
- Динамическая типизация компенсируем: подсказки типов везде, тест на границы слоёв, короткие функции.
- Критичные компоненты (политики, vault, финансовый контур) проектируются как отдельные модули за контрактами,
  чтобы при необходимости их можно было переписать на другом языке, не трогая остальное.
