# ADR-006 — Контракты моделей и инструментов (v0)
**Статус:** Draft

## Решение
- `ModelPort`: `capabilities` + `complete()`. Паспорт: локальность, макс. зона, контекст, вызов инструментов,
  структурированный вывод, модальности, цена, качество (позже из evals).
- Адаптер обязан превращать любые сбои вендора в `ModelError`; роутер идёт к следующей модели.
- `ToolSpec`: имя, риск, capability, макс. зона данных, idempotent. Обработчики хранятся в реестре, вызов — только через `ToolPort`.

## Последствия
Смена модели не затрагивает ядро, но **промпты и агенты меняются вместе с моделью** — это ловят evals (Phase 1).
Контракт станет v1 после walking skeleton и работы с первым реальным адаптером.
