# ADR-016 — Настройки компьютера и установка на «голый» Windows
**Статус:** Accepted. Установщик проверен в Windows Sandbox (чистая Windows без Python, Git, winget и VC++), см. «Проверка».
Дополняет ADR-014 (установщик).

## Контекст
1. Папки J.U.R.A. (модели, копии, данные) задавались переменными окружения. В первый же день это подвело:
   VS Code был запущен раньше, чем появилась переменная, J.U.R.A. её не увидел и заново скачал 640 МБ модели на почти полный диск C:.
2. Владелец хочет поставить J.U.R.A. на компьютер, где есть только Windows 10: ни Python, ни Git, ни winget, ни моделей.
   Одним запуском, и чтобы так оставалось и дальше, когда проект растёт.

## Решение
**Настройки компьютера — файл `jura.local.json` в корне проекта** (`src/jura/machine.py`), в git не попадает.
Ключи: `home` (данные), `models_dir` (модели), `backup_dir` (копии), `local_model` (модель в Ollama).
Порядок: переменная окружения (если задана) → файл → значение по умолчанию. Команда `python -m jura config [set|unset]`.
Секретов в файле нет, только пути. Тесты указывают свой файл через `JURA_CONFIG` и не видят настройки компьютера.
- Модели распознавания всегда качаются в `models_dir/hf`: J.U.R.A. сам задаёт HF_HOME своему процессу.
- Ollama — отдельная программа, она читает только свою переменную `OLLAMA_MODELS`. Установщик задаёт её **до** установки Ollama,
  а `jura setup`, если сам запускает сервер Ollama, передаёт ему ту же папку.
- `setup` записывает `local_model`, а `init` подключает эту модель к новому хранилищу. Ручной `model add` больше не нужен.

**Установщик (`install.cmd` → `bootstrap.ps1` → `scripts/install.py`):**
| Что | Как без winget (чистый Windows 10) |
|---|---|
| Python 3.12 | `bootstrap.ps1` скачивает официальный установщик с python.org, ставит для пользователя без прав администратора |
| Visual C++ Runtime (нужна onnxruntime: распознавание речи и голос) | `https://aka.ms/vs/17/release/vc_redist.x64.exe /install /quiet` |
| Git | последний релиз git-for-windows (через API GitHub), Inno Setup `/VERYSILENT` |
| Ollama | `https://ollama.com/download/OllamaSetup.exe /VERYSILENT` |
| Библиотеки | `pip install -e .` |
| Модели (Parakeet, голос Piper, gemma3 → jura-gemma3), Chromium | `jura setup` |

Если winget есть, программы ставятся через него, а прямое скачивание остаётся запасным путём. После каждой установки PATH
перечитывается из реестра, поэтому новые программы видны сразу, без перезапуска окна. Папки моделей и копий установщик
спрашивает и предупреждает, если на диске с профилем мало места. Можно и флагами: `--models-dir`, `--backup-dir`, `--yes`.

**Правило проекта:** всё, что нужно J.U.R.A. и не ставится через pip, добавляется в установщик: системная программа — одной записью
в `SYSTEM_PACKAGES` (winget id, прямая ссылка, тихие ключи, как понять, что уже стоит), модель — в `jura setup`. Тест
`test_every_system_package_can_be_installed_without_winget` не даст добавить программу без пути для чистого Windows.

## Альтернативы
- **Переменные окружения:** их не видят уже запущенные программы. Отклонено как основной способ, оставлено для переопределения.
- **Настройки в зашифрованном хранилище:** пути нужны до разблокировки (setup, голос, установщик). Отклонено.
- **Самодостаточный архив с Python и моделями внутри (~7 ГБ):** большой и быстро устаревает. Отклонено, скачиваем с официальных источников.
- **Только winget:** на чистом Windows 10 его часто нет. Отклонено как единственный путь.

## Последствия
- Источники доверия при установке: python.org, aka.ms (Microsoft), github.com (git-for-windows), ollama.com, Hugging Face, PyPI.
  Всё по https. Хэши установщиков не закреплены, это пробел (см. THREAT_MODEL).
- VC++ Runtime и Git (для всех пользователей) просят права администратора: Windows покажет запрос, нужно согласиться.
- Драйвер видеокарты установщик не ставит. Ollama работает и без него, только медленнее (на процессоре). Драйвер NVIDIA ставится вручную.
- Windows Sandbox повторяет сборку той Windows, на которой запущен (здесь Windows 11). Windows 10 отличается в мелочах,
  поэтому первая установка на ПК владельца — финальная проверка.
